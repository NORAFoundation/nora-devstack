# nora-devstack

**Status:** `planned-prepublication` · **Portfolio wave:** D

Reproducible synthetic local environment for contributing across the NORA OSS ecosystem without private infrastructure or Matter data.

## Why this repository exists

This repository is one bounded component of the NORA Foundation public OSS portfolio. It is designed for independent use and contribution while remaining compatible with NORA One through explicit contracts.

Read `CHARTER.md` first. `PUBLICATION_GATES.md` describes what must be true before public release.

## Current maturity

Scaffolded / pre-publication. Repository structure, contracts, tests and source-reconciliation controls exist; implementation completeness is **not** claimed.
