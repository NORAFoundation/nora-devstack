# Governance

NORA Foundation stewards this repository as public-interest infrastructure.

## Decision rule
Consequential changes to evidence semantics, scope/authorization, public contracts, security posture, repository boundaries, provider strategy, or compatibility require an ADR or explicit canonical documentation update.

## Public/private boundary
This repository must remain independently usable and must not require access to private NORA One source code, private Matter data, production credentials, or operator-only controls.

## Current scaffold state
This repository has been created as an independent Git repository inside an unversioned portfolio workspace. Public visibility is not authorized merely by this scaffold.
